The main program of the project is in the "ConsisID" folder. First, you need to configure the environment and download the model according to the README of ConsisID. After that, you can use the program based on README_20717283.

The "Replace_code" contains my modifications to ConsisID, which can optimize the VRAM (Video Random Access Memory) load to a certain extent.

The "test_program" contains the testing method "visionreward" and the prompt optimization projects for comparison, such as "vpo"  and "prompt a video". If you want to give it a try, you also need to configure the environment and download the models on your own.
